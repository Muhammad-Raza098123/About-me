# About Me

I'm passionate about building a strong, well-rounded foundation in both systems-level and application-level software development, with the long-term goal of becoming a **versatile software engineer** — someone equally comfortable writing efficient low-level code and designing user-facing applications that solve real problems.

I approach computer science as a discipline built from the ground up: understanding how a computer actually executes instructions before abstracting away from it, and understanding the fundamentals of logic, math, and architecture before relying on frameworks and libraries. ## Career Interests

My career interests span **low-level and systems development**, including C programming, memory management, operating system fundamentals, and how software interacts with hardware. I'm equally drawn to **high-level software engineering**, where the focus shifts to clean architecture, data structures and algorithms, and writing code that is maintainable and scalable as systems grow in complexity.

Beyond systems programming, I'm working toward **web development** — building functional, responsive applications that are usable and reliable — and **application development**, designing cross-platform tools that solve practical, everyday problems for real users. My goal is not to specialize narrowly, but to be able to move fluidly between the layers of a system: from the hardware-adjacent code at the bottom to the interface a user actually interacts with.
